# PDF Documentation

This directory contains SOC 2 related PDF documentation used for the vector database.

## Required PDFs:
- **SOC 2 TSC Criteria** - AICPA Trust Services Criteria documentation
- **SSAE 21 Standards** - Attestation standards documentation
- **SOC 2 Implementation Guides** - Any supplementary SOC 2 guidance

## Usage:
Place your PDF files here, then run:
```bash
python prepare_vectors.py
```

The script will automatically process all PDFs in this directory.

## Where to get them
The PDFs are AICPA publications and are not redistributed in this repository.
Download them from [aicpa-cima.com](https://www.aicpa-cima.com/) (2017 Trust Services Criteria with revised points of focus 2022; illustrative SOC 2 report under SSAE 21) and put them in this folder.
